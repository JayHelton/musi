# Complete A-Centered Sweep-Picking Inversion Library

This manual contains 321 complete ascending-and-descending patterns: one standardized, playable close-position voicing for every chord-tone inversion of every listed chord on 3-, 4-, and 5-string sets.

It does not claim to list every possible fretboard voicing. Octave displacement, open voicings, duplicated chord tones, string skipping, and alternate string sets create effectively unlimited additional shapes.

Setup and notation





Standard tuning: E A D G B e



3-string set: G-B-e



4-string set: D-G-B-e



5-string set: A-D-G-B-e



Sweep downward through ascending string changes.



Sweep upward through descending string changes.



h = hammer-on; p = pull-off.



Five- and six-note extensions use sweep/legato hybrids on smaller string sets so every chord tone is present.



An inversion is determined by the lowest chord tone. Root position has A in the bass; later inversions place each subsequent chord tone in the bass.



Practice method





Play each pattern slowly as one continuous motion in each direction.



Stop the previous string as the next string sounds; do not let the shape ring like a strummed chord.



Practice root position through the final inversion, then reverse the order.



Move the finished family through all 12 keys only after the A-centered shapes are clean.

Diminished-scale application



A whole-half diminished

Scale: A B C D Eb F F# G#

The primary sweep structure is Adim7: A C Eb Gb/F#. Its root position and three inversions are already listed above on every string set.

Because a fully diminished seventh chord is symmetrical, the same pitch set may be named Adim7, Cdim7, Ebdim7, or F#dim7. Move a dim7 fingering three frets at a time to sequence the same diminished function through higher registers.

A second diminished seventh structure exists inside the scale: B D F G#.

A half-whole diminished

Scale: A Bb C C# Eb E F# G

Directly useful chord families included in this manual:





A7



A7b5



A7b9



A7#9



A13



A13b9



A7b9#11

The classic upper structure is Bbdim7. It is conventionally spelled Bb - Db - Fb - Abb; over an A pedal, read it enharmonically as Bb - C# - E - G, producing b9 - 3 - 5 - b7, or A7b9.

To obtain the Bbdim7 upper-structure sweeps, move every Adim7 fret upward by one fret. The same chord then repeats at Bb, Db, E, and G in three-fret cycles.

A7b9b13 is included as a useful altered-dominant sweep, but its b13 (F) is not part of the A half-whole diminished scale. Do not treat it as a strict diminished-scale voicing.

Riff integration





Use a low A pedal beneath short Bbdim7 sweeps to imply A7b9.



Sequence Bbdim7 inversions in three-fret steps, then resolve to A5, Am, or A7.



Alternate an A pedal with notes Bb-C-C#-Eb-E-F#-G for half-whole dominant tension.



Alternate an A pedal with notes B-C-D-Eb-F-F#-G# for whole-half diminished motion.



Treat the sweep as punctuation between riff cells rather than sustaining every chord tone.
